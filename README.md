# Finpath — ИИ-платформа для управления финансами

Сайт по мотивам концепта [Finpath (Behance, Kateryna Sharova)](https://www.behance.net/gallery/248420885/Finpath-I-AI-Powered-Finance-SaaS-Dashboard-UIUX).
Вся текстовая часть — на русском. Зависимостей и сборки нет: чистые HTML, CSS и JS.

## Структура

| Файл | Что внутри |
|------|-----------|
| [index.html](index.html) | Лендинг: герой с превью дашборда, о платформе, «проблема и решение», возможности (bento), метрики, аналитика, шаги, тарифы, FAQ, CTA, футер |
| [dashboard.html](dashboard.html) | Дашборд: баланс, инвестиции, ИИ-ассистент, денежный поток, операции, карты, цели, категории, инсайт |
| [css/styles.css](css/styles.css) | Токены дизайна, примитивы, секции лендинга, адаптив |
| [css/dashboard.css](css/dashboard.css) | Компоненты дашборда (общие для превью в герое и самой страницы) |
| [js/main.js](js/main.js) | Тема, меню, появление блоков, график потока, демо ИИ-ассистента |

## Как открыть

Достаточно открыть `index.html` в браузере — всё работает и по `file://`.
Если нужен локальный сервер:

```bash
python -m http.server 5178
```

## Дизайн-система

**Шрифт** — [Onest](https://fonts.google.com/specimen/Onest) (300–800). В референсе использован
Aeonik; Onest — ближайший геометрический гротеск с полной поддержкой кириллицы,
доступный в Google Fonts.

**Цвета** сняты пипеткой с макетов референса:

| Токен | Тёмная (основная) | Светлая |
|-------|-------------------|---------|
| `--bg` | `#0a0a0a` | `#f4f4f2` |
| `--surface` | `#161616` | `#ffffff` |
| `--surface-3` | `#282828` | `#e5e5e2` |
| `--lime` | `#d7ff67` | `#c8f04a` |
| `--accent-ink` | `#d7ff67` | `#5f7d14` |

`--lime` — для плашек, фонов и графики. `--accent-ink` — для **текста и иконок**:
на светлой теме сам лайм на белом даёт контраст ниже 4.5:1, поэтому он темнеет.

**Плотность** — шкала 8–96 px, скругления от 10 px до pill.
**Движение** — 150–300 ms, easing `cubic-bezier(0.16, 1, 0.3, 1)`;
`prefers-reduced-motion` отключает анимации.

## Заметки по реализации

- **Диаграмма баланса** — метаболы: несколько SVG-кругов под фильтром
  `feGaussianBlur` + `feColorMatrix`, за счёт которого между ними появляются
  перетяжки. Заливки заданы через `var(--surface-3)` / `var(--lime)`, поэтому
  фигура сама подхватывает тему.
- **Линза в «Проблема и решение»** — `border-radius` такую форму не даёт (браузер
  сжимает радиусы до эллипса), поэтому подложен растягивающийся SVG-path.
- **Появление блоков** включается классом `js-reveal` на `<html>` и только после
  создания `IntersectionObserver`. Плюс страховка на 1.6 s: если наблюдатель не
  отдал ни одной записи, всё показывается принудительно — контент не может
  остаться невидимым из-за ошибки JS.
- **Тема** запоминается в `localStorage` (ключ `finpath-theme`).
- Данные в интерфейсе демонстрационные, захардкожены в разметке и в `FLOW`
  внутри `js/main.js`.

## Проверено

Chrome (headless), рендеринг и функциональные проверки:

- разрешения 375 / 768 / 1440 px — горизонтального скролла нет;
- тёмная и светлая темы;
- переключение «Доход / Расход / Накопления» перестраивает график;
- демо ИИ-ассистента, выбор строки инвестиций, бургер-меню, переключатель темы;
- в консоли ошибок нет.
